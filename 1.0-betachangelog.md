# New Drivers
snd.drv: an driver for sounds, and manages system sounds like logout, login, info, error, warning.. etc.

pwr.drv: manages battery, energy, keeps values.

input.drv: manages input and saves last pressed keys.

netdrv.drv: driver for network and internet.
